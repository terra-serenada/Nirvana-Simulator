Terra Chemica · Build 1.1. Build 1.1 menambahkan reservoir fluida geologi, infiltrasi, sirkulasi hidrotermal, presipitasi parsial, serta ledger H₂O yang telah bereaksi. Presisi di sini berarti konservasi atom dan energi internal model dapat diuji serta semua asumsi dilabeli. Audit muatan masih terbatas karena build ini hanya memakai spesies netral; pH, ion, aktivitas, dan kesetimbangan mineral-air penuh belum dimodelkan. Model belum memprediksi fluks Bumi purba. Tidak ada sel, DNA, ATP biologis, fotosintesis, atau pembelahan di dalam file ini.
